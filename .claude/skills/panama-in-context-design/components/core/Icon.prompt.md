Inline Heroicons glyph that inherits `currentColor` — use anywhere the product would reach for `@heroicons/react`.

```jsx
<Icon name="academic-cap" size={24} />
<Icon name="check-circle-solid" size={20} color="var(--color-brand)" />
```

Outline names (e.g. `map`, `user-group`, `calendar-days`) for interface controls; append `-solid` (e.g. `check-circle-solid`, `star-solid`) for filled inline accents. `ICON_NAMES` lists everything bundled. Color it by setting `color` on the icon or any ancestor.
