Brand-checked checkbox with an inline label and optional description line.

```jsx
<Checkbox label="I need transportation from my hotel" />
<Checkbox label="Casco Antiguo: Plazas & Churches" description="3-hour walking tour" defaultChecked />
```

Uses the native control with `accent-color` set to brand. Fully controlled (`checked` + `onChange`) or uncontrolled (`defaultChecked`).
