Native dropdown with the inset-ring field treatment and a chevron. Pass `<option>`s as children.

```jsx
<Select label="I am interested in" defaultValue="">
  <option value="" disabled>Select an option</option>
  <option value="field-trips">Academic Field Trips</option>
  <option value="tours">Private Tours</option>
</Select>
```

Same `label` / `hint` / `error` / `required` props as `Input`.
