Read the `readme.md` file within this skill, and explore the other available files.

If creating visual artifacts (slides, mocks, throwaway prototypes, etc.),
copy assets out and create static HTML files for the user to view. If
working on production code, you can copy assets and read the rules here to
become an expert in designing with this brand.

Key things to load:
- `readme.md` — brand context, content & visual foundations, iconography.
- `styles.css` + `tokens/` — link `styles.css` for all CSS custom
  properties (brand blue `#1095d3`, gray neutrals, type, spacing, radii,
  shadows, motion).
- `components/` — React primitives (`Icon`, `Button`, `Badge`, `Card`,
  `Input`, `Select`, `Checkbox`, `Alert`). Each has a `.prompt.md` with
  usage. In a compiled DS context they live on
  `window.PanamaInContextDesignSystem_0dba89`.
- `assets/` — logos, heritage photography, and `heroicons.js` (inline
  Heroicons for plain-HTML use via `<i data-hicon="…">`).
- `ui_kits/website/` — a full interactive recreation of the marketing site
  to copy patterns from (hero, sections, tours grid, booking, contact).
- `ui_kits/slides/` — PowerPoint-style presentation templates (title,
  section, bullets, two-column, full image, timeline, map, closing) as a
  navigable, PPTX-exportable 1280×720 deck.
- `ui_kits/study_guides/` — portrait, print-ready study-guide templates
  (title, section, bullets, photo-top, vertical timeline, numbered, four
  long-form reading layouts, closing) as one printable PDF document.
- `ui_kits/social/` — Instagram post templates (1080×1350): two "Sabías
  que" fact cards (blue + warm-gray) and a blog announcement. These use the
  **accent-orange** tokens (`--accent-*`) and Google **Caveat** for the
  handwriting — the one place orange leads instead of brand blue.

House rules: one brand-blue accent on a white canvas; system sans type
with semibold tight-tracked headings; generous whitespace; warm Panamanian
heritage photography in `rounded-2xl` frames with a hairline ring; Heroicons
(outline for UI, solid for accents); **bilingual EN/ES** copy; **no emoji**.
Avoid gradient blobs, hand-drawn icons, and heavy shadows.

If the user invokes this skill without any other guidance, ask them what
they want to build or design, ask some questions, and act as an expert
designer who outputs HTML artifacts _or_ production code, depending on the
need.

## Installation (Claude Code)

Place this folder so Claude Code can discover it as a skill:

- **In the `panama-in-context` repo** (shared with the team):
  `.claude/skills/panama-in-context-design/`
- **For yourself, across all projects:**
  `~/.claude/skills/panama-in-context-design/`

The folder must keep `SKILL.md` at its root (alongside `readme.md`,
`styles.css`, `tokens/`, `components/`, `assets/`, `ui_kits/`). Once in
place, invoke it in Claude Code with: *"use the panama-in-context-design
skill"*.

### Note on `_ds_bundle.js`
The compiled React bundle (`_ds_bundle.js` / `_ds_manifest.json`) is
generated by the design-workspace compiler and is **not** part of this
download. Claude Code does not need it — design from the component
**source** instead: `components/**/*.jsx` + `.d.ts` + `.prompt.md`, the
tokens in `styles.css`, the `assets/`, and the patterns in `ui_kits/`.
When building plain-HTML artifacts, load icons via `assets/heroicons.js`
(`<i data-hicon="…">`) rather than the bundle.
